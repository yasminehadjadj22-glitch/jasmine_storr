# نظام إدارة المبيعات والمشتريات 📊

نظام شامل لإدارة المبيعات والمشتريات مع حساب الجرد التلقائي، مصمم خصيصاً للمحلات التجارية الصغيرة والمتوسطة.

## ✨ المميزات

- 📈 **إدارة المبيعات**: تسجيل وتتبع جميع عمليات البيع
- 🛒 **إدارة المشتريات**: متابعة المشتريات والموردين
- 🗑️ **إدارة الهدر**: تسجيل المواد التالفة أو المهدرة
- 👤 **الاستعمال الشخصي**: تتبع المواد المستخدمة شخصياً
- 📝 **الملاحظات**: تدوين الملاحظات المهمة
- 📦 **إدارة الطلبات**: متابعة الطلبات والتسليم
- 📊 **الجرد التلقائي**: حساب الجرد الشهري والسنوي تلقائياً
- 🌙 **الوضع الليلي**: دعم كامل للوضع الداكن
- 📱 **متجاوب**: يعمل على جميع الأجهزة

## 🚀 النشر على الإنترنت

### نشر سريع (5 دقائق)

```bash
# 1. تثبيت Vercel CLI
npm install -g vercel

# 2. تسجيل الدخول
vercel login

# 3. النشر
cd /workspace/app-bchw39iq1hc2
vercel --prod
```

### أو استخدم السكريبت الجاهز

**Windows:**
```cmd
deploy.bat
```

**Mac/Linux:**
```bash
./deploy.sh
```

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 18 + TypeScript + Vite
- **UI**: Tailwind CSS + shadcn/ui
- **Backend**: Supabase (PostgreSQL + Authentication + Storage)
- **Routing**: React Router v7
- **Forms**: React Hook Form + Zod
- **State**: React Context + Hooks
- **Icons**: Lucide React
- **Deployment**: Vercel (مجاني)

## 📁 هيكل المشروع

```
├── src/
│   ├── components/      # مكونات واجهة المستخدم
│   ├── pages/          # صفحات التطبيق
│   ├── contexts/       # Context للحالة العامة
│   ├── hooks/          # Custom Hooks
│   ├── services/       # خدمات قاعدة البيانات
│   ├── types/          # تعريفات TypeScript
│   └── lib/            # مكتبات مساعدة
├── supabase/
│   ├── functions/      # Edge Functions
│   └── migrations/     # Database Migrations
├── public/             # ملفات ثابتة
└── scripts/            # سكريبتات مساعدة
```

## 🔧 التطوير المحلي

### المتطلبات

- Node.js ≥ 20
- npm ≥ 10

### التثبيت

```bash
# 1. تحميل المشروع
git clone <repository-url>
cd app-bchw39iq1hc2

# 2. تثبيت الحزم
npm install

# 3. إعداد متغيرات البيئة
# انسخ .env.example إلى .env وأضف قيم Supabase

# 4. تشغيل المشروع
npm run dev -- --host 127.0.0.1
```

### الأوامر المتاحة

```bash
npm run dev          # تشغيل بيئة التطوير
npm run build:prod   # بناء للإنتاج
npm run preview      # معاينة البناء
npm run lint         # فحص الكود
```

## 🔐 الأمان

- ✅ **Row Level Security (RLS)**: حماية البيانات على مستوى الصفوف
- ✅ **Authentication**: نظام مصادقة آمن
- ✅ **HTTPS**: تشفير تلقائي في الإنتاج
- ✅ **Environment Variables**: حماية المفاتيح السرية
